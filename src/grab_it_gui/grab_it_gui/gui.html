Click-to-grasp needs MoveIt + grasp_from_click on the AGX (Isaac container). Nano cameras + arm already up:

Launch grasp stack
bash /workspaces/isaac_ros-dev/scripts/grabit_arm_bringup.sh

That starts robot_description, MoveIt, and grasp_from_click. If MoveIt is already running and you only need the grasp node:

bash /workspaces/isaac_ros-dev/scripts/grasp_bringup.sh
  1. Click the object in D435i. Wait for the green cube and XYZ.
  2. Grasp at point — open, approach the click, then the scripted pinch closes (load or a foam stall). Holding the pole is success. The arm does not lift. Pan locks. The shoulder does not fold back. One 1 cm retry if the first close misses.
  3. Cancel aborts. Unlock pan frees the pan slider.

Imitation

Collect and replay tabletop picks. Same teleop and click-to-grasp as User Control. If status stays “Recorder idle”, the recorder is not running.

1. AGX host → Isaac container
docker exec -it -u admin -w /workspaces/isaac_ros-dev isaac_ros_dev-aarch64-container bash
2. Record (leave this running — it sources the workspace)
bash /workspaces/isaac_ros-dev/scripts/il_record.sh

Do not run bare ros2 launch in a fresh shell — Humble alone cannot see grab_it_il. The script sources install/setup.bash for you.

Oracle demos from Grasp at point also need the grasp stack (grabit_arm_bringup.sh).

3. Play (second container shell; GUI STOP armed)
bash /workspaces/isaac_ros-dev/scripts/il_play.sh
# optional ACT checkpoint:
bash /workspaces/isaac_ros-dev/scripts/il_play.sh \
  /workspaces/isaac_ros-dev/datasets/lerobot/outputs/act_tabletop_pick/checkpoints/last/pretrained_model

No checkpoint → open-loop replay of the latest episode.

RECStart an episode. Drive with sticks or run Grasp at point.

DISCARDDrop the take.

STOPStop recording or playback.

Episodes: /workspaces/isaac_ros-dev/datasets/tabletop_pick/. Aim for 30–50 successful picks.

Calibration

Teach-cal for click-to-grasp. D435i clicks do not send a grasp point.

Launch teach-cal (Isaac container)
bash /workspaces/isaac_ros-dev/scripts/calibration/teach_cal_bringup.sh
  1. Free arm — torque off. Support the arm by hand.
  2. Move the gripper tip to the landmark.
  3. Hold arm (same button) — torque on.
  4. Save tip pose.
  5. Sleep→taught to check (clear the workspace).
  6. Set Samples (2–40) and Run pan cal. Arm stays at the taught tip; pan sweeps.
  7. Abort cal to stop a sweep or goto.

HOME / SLEEP still work. Sticks are hidden.

Apply a finished sweep
python3 /workspaces/isaac_ros-dev/scripts/calibration/grasp_cal_analyze.py teach_cal.jsonl
